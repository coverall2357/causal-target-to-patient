## Method

1. Trial titles and intervention names were read from the AACT pull (`ra_trials_20261022.csv`, `ra_interventions_20261022.csv`) to see what each name stands for.
2. Codes were searched on the web with "mechanism" or "target", preferring a paper, trial record, or company source. Each cited page was fetched to take a verbatim quote for `evidence`.
3. Where a page couldn't be fetched (PubMed Central and ClinicalTrials.gov pages don't render for automated fetches), the page or paper title was used as evidence, and `notes` says "Paper title", "Trial title" or "Page title".
4. Code-to-name links were checked against the ChEMBL synonyms in the local ChEMBL cache where ChEMBL has the molecule:
   - R788 = fostamatinib (synonym R-788)
   - BT061 = tregalizumab (BT-061)
   - JNJ 38518168 = toreforant
   - VIB4920 = dazodalibep
   - BIBR 796 BS = doramapimod (the registry's typo of BIRB 796; synonym BIRB-796)
   - HuMax-CD20 = ofatumumab
   - CCX 354-C = CCX354-C
   - M2591 = evobrutinib (the registry's typo of M2951)
5. Otherwise the link comes from the cited source. Examples: TS-152 = ozoralizumab (jRCT), Z102 = prednisolone + dipyridamole (EU CTR), ENIA11 = TuNEX etanercept (GaBI).
6. Target IDs use the ChEMBL target ID wherever the local cache has the target, so that drugs on the same target share an ID. Otherwise they use `GENE:<symbol>`.

## Decisions

**Fludarabine (3 manual mechanism rows).**
- ChEMBL has the nucleoside without a mechanism.
- Its active triphosphate inhibits DNA polymerase α (POLA1), ribonucleotide reductase (RRM1) and DNA primase (PRIM1), per DrugBank.
- It is an RA treatment in NCT00001677 (methotrexate ± fludarabine). In NCT06733935 it is lymphodepletion before NKX019 (see Known issues).

**Cell therapies.**
- Rapcabtagene autoleucel, a CD19 CAR-T, maps to CD19.
- These are recorded as deliberately unmapped (`unmapped_decisions.csv`) because they act through broad immunomodulation, not a single molecular target:
  - mesenchymal stromal cell products (6 trial names plus 2 non-labelling names)
  - MSC secretome
  - placenta-derived cells (cenplacel-L)
  - autologous apoptotic cells
  - HSP70-peptide tolerogenic dendritic cells
- **Correction:** NCT07715045's "UC-MSC Secretome" had been matched to solizmestrocel through the ChEMBL synonym "Uc-msc". A secretome is not the cells, so an override now sends it, and "Messenchymal stem cell secretome", to the unmapped entry `msc secretome`.

## Known issues

- **Conditioning agents.** Fludarabine and cyclophosphamide are lymphodepletion in NCT06733935 (NKX019). The mapping counts them as tested therapeutics because overrides apply to a name across all trials. Fixing this needs per-trial roles, a code change for later.
- **Name cleaning.** Many unmatched codes differ from ChEMBL's synonyms only by a hyphen (BT061 vs BT-061, R788 vs R-788). Some names also carry a "Drug:" prefix. Cleaning rules for both would resolve such names without overrides. That is a code change to discuss.

## Effect on the mapping

The full pipeline was rerun on 2026-10-22 (pull, mapping, worklist, evidence; outputs stamped 20261022). It was compared trial by trial with the same-day outputs saved before this batch, which are kept in `backups/*_20261022_before_b3.csv`. The AACT pull itself was unchanged: 1,223 eligible trials.

**Trial sets.** The 20 trial exclusions moved 20 labelling trials to `excluded`; there are now 33 excluded trials. None of the 20 was a contrast test before.

**Contrast classes.** 113 trials changed class or trial set.
- Of the 159 unmapped labelling trials, 106 left that class:
  - 46 became target contrasts
  - 1 became head-to-head
  - 15 became same-target
  - 5 became single-intervention
  - 4 became uncontrolled
  - 16 became excluded-therapy
  - 19 went to the `excluded` set (2 excluded-therapy, 1 uncontrolled, 16 unmapped)
- 53 labelling trials remain unmapped.
- 2 unmapped ongoing trials became mapped: 1 target contrast, 1 uncontrolled.
- One uncontrolled labelling trial (NCT01044498, the oral-contraceptive study) moved to `excluded`.
- Four trials that were already mapped changed class:
  - **NCT05489224** (CT-P47 vs RoActemra) and **NCT05842213** (AVT05 vs Simponi): target contrast → same-target. Both are biosimilar trials that had counted as target contrasts only because the biosimilar was unmapped. This corrects them.
  - **NCT00537667** (SPECTRA: anakinra vs anakinra + pegsunercept): same-target → target contrast on TNF.
  - **NCT02467504** (low-dose IL-2): target contrast → head-to-head. The IL-2 receptor is now mapped, and loxoprofen, an NSAID that isn't on the excluded list, is still counted as tested (see below).
- Two trials kept their class but gained targets:
  - NCT02885181: GS-9876 adds SYK.
  - NCT06733935: fludarabine adds POLA1, PRIM1 and RRM1, and NKX019 now uses ChEMBL's CD19 ID (see Known issues).
