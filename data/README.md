# RA trial-to-target map

What has been tried in rheumatoid arthritis (RA), and against what? This folder answers that question at the level of molecular targets, for every RA interventional trial registered on ClinicalTrials.gov that passed the inclusion rules. Each trial records:

- which drugs it tested;
- which targets those drugs act on, and where each mapping came from;
- what the trial compares at the target level;
- how much outcome evidence is available for it.

It is the first rung of the project (see the main [README](../README.md)). Outcome labels (whether each trial met its primary endpoint) are not part of this release. They come in the next rung, once they've been checked against hand labels.

## Files

| File | Rows | Contents |
|---|---|---|
| `ra_trials.csv` | one per trial | Registry fields, trial set, contrast class, contrasted targets and genes, evidence tier |
| `ra_trial_targets.csv` | one per trial, intervention, name component and target | How each intervention name was mapped to a molecule and its targets, with provenance |
| `summary.json` | — | Headline counts and the date of the pipeline outputs used |

The files are generated by `scripts/export_map.py` from the pipeline's dated outputs; `summary.json` gives the date (`source_stamp`). Don't edit them by hand: corrections go in `curated/trials/` with a source, and the map is regenerated.

## How to read it

**Trial sets** (`trial_set`):

| Value | Meaning |
|---|---|
| `labelling` | Phase 1/2 to phase 3, no longer running (withdrawn trials are left out). These trials can have a known outcome and form the benchmark. |
| `context` | Phase 4, no longer running. Kept for context; not part of the benchmark. |
| `ongoing` | Any phase, still recruiting or active. |
| `excluded` | Set aside by a curated decision (`exclusion_reason` says why). Examples: RA complications such as lung disease, vaccine-response studies, primary endpoints that aren't efficacy. |

**Contrast classes** (`contrast_class`). What a trial compares, at the target level:

| Value | Meaning |
|---|---|
| `target_contrast` | The tested drug's targets differ from the control's (most often drug vs. placebo). **A test of the targets.** |
| `head_to_head` | Two active drugs on different targets compared directly. **Also a test.** |
| `same_target` | Every arm hits the same targets, e.g. a biosimilar vs. its originator, or two doses. |
| `uncontrolled` | No control arm. |
| `single_intervention` | One tested drug, no placebo, and no comparator arm recorded. |
| `excluded_therapy` | Only conventional or symptomatic therapies are tested (e.g. methotrexate, steroids, NSAIDs), which the benchmark doesn't count as target tests. |
| `unmapped` | At least one tested drug couldn't be mapped to a target. |
| `no_test` | No tested intervention remains after the rules above. |

The benchmark's **contrast tests** are the labelling trials in the first two classes. `summary.json` has the counts.

**Contrasted targets.** `contrast_targets` holds ChEMBL target IDs, separated by `;`. Targets curated without a ChEMBL ID are written `GENE:<symbol>`. `contrast_genes` gives the same targets as sorted gene symbols. A protein family or complex contributes all its genes (the JAK family gives JAK1;JAK2;JAK3;TYK2).

**Evidence tier** (`evidence_tier`). The strongest outcome evidence available for the trial:

| Value | Evidence |
|---|---|
| `primary analysis` | Posted primary-outcome results with an analysis reporting a p-value |
| `primary results` | Posted primary-outcome results without such an analysis |
| `publication` | A linked publication |
| `stop reason` | Only a reason for stopping early |
| `none` | Nothing beyond the registration |

**Mapping status** (`mapping_status` in `ra_trial_targets.csv`):

| Value | Meaning |
|---|---|
| `mapped` | Mapped to a molecule with at least one target |
| `excluded_therapy` | A conventional or symptomatic therapy. The targets are shown but aren't counted as tested. |
| `excluded_name` | A name that isn't a specific drug (e.g. "biologics"), set aside by a curated decision |
| `no_mechanism` | Matched to a molecule, but no mechanism is recorded for it (e.g. fish oil) |
| `unmapped` | Not matched to a molecule |
| `placebo` | Not mapped |

**Provenance** (`ra_trial_targets.csv`):
- `mapping_basis` says how the name was matched:
  - `chembl_name`: by its ChEMBL name
  - `chembl_synonym`: by a ChEMBL synonym
  - `curated_override`: by a curated override
- `mechanism_source` is `chembl` or `curated`. For curated mechanisms, `mechanism_reference` gives the cited source.
- Every curated decision, with its quote, confidence and batch, is in [`curated/trials/`](../curated/trials/). Each batch has a log in [`docs/curation/`](../docs/curation/).

## Known limitations

- **Some trials are misclassified.**
  - A few extension studies are still counted as `target_contrast`.
  - Some combination or sequential-therapy trials are counted as `head_to_head`.
  - Conditioning agents given before a cell therapy (such as fludarabine) are counted as tested drugs.

  These are listed in the main README's open questions.
- **Arm roles come from registry fields.** Whether an intervention is investigational, comparator or background is inferred from registered arm types and names. Registrations vary in quality.
- **Some drugs are unmapped.** 52 labelling trials are `unmapped`. Herbal and multi-component products are deliberately left unmapped.
- **The map reflects a snapshot.** ClinicalTrials.gov changes daily; this release is as of the date in `summary.json`.
